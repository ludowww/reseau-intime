## 3. Verdict produit

### 3.1 Ce qui fonctionne

Le corpus possède :

- des routes différenciées ;
- une montée progressive du désir ;
- des initiatives propres aux personnages ;
- des propositions adultes explicites ;
- des règles de consentement ;
- des possibilités de retrait ;
- des rencontres physiques ;
- des après-coups ;
- des conséquences relationnelles.

La forme globale de la Saison 1 est cohérente :

```text
vie ordinaire
→ lignes privées
→ incarnation
→ convergence
→ conséquences
→ découverte
→ engagements incompatibles
→ paiement
→ résolutions
```

### 3.2 Ce qui manque

Plusieurs routes maximales suivent actuellement cette structure :

```text
désir reconnu
→ proposition
→ consentement
→ transition hors téléphone
→ événement physique résumé
→ après-coup
```

Le contenu adulte existe donc comme fait narratif, mais pas toujours comme expérience réellement délivrée au joueur.

Le risque produit est important :

- le joueur construit une route pendant de nombreuses journées ;
- le personnage prend enfin une initiative ;
- le cadre est négocié ;
- le joueur atteint l’éligibilité maximale ;
- le jeu coupe précisément au moment attendu comme récompense.

Cette ellipse peut fonctionner ponctuellement.

Elle ne doit pas être la réponse systématique du jeu à ses meilleurs parcours adultes.

### 3.3 Décision

Les routes maximales de Marie, Sandra et Mathilde doivent pouvoir délivrer une véritable séquence adulte représentée.

Pauline et Raphaëlle doivent recevoir un payoff adulte intermédiaire clairement supérieur à une simple promesse future.

Nico ne reçoit aucune scène sexuelle directe avec Player.

## 4. Contrat commun de représentation

### 4.1 Deux natures d’image seulement

Le projet conserve deux catégories narratives.

#### Photo diégétique

La photographie existe dans l’univers.

Elle possède :

- un créateur ;
- une intention ;
- une sélection ;
- une audience ;
- une règle de conservation ;
- une règle de circulation ;
- un éventuel droit de retrait.

Elle apparaît d’abord :

- dans une conversation ;
- dans un groupe ;
- dans un relais crédible ;
- ou dans une scène où un personnage la montre réellement.

Elle peut ensuite devenir consultable dans la Galerie si son état le permet.

#### Image de scène

L’image représente un moment vécu par le joueur.

Elle n’existe pas comme fichier pris par un personnage.

Elle convient pour :

- une proximité physique ;
- un baiser ;
- une scène sexuelle ;
- une rencontre sans caméra ;
- un après-coup ;
- une séparation ;
- une situation physiquement vécue hors téléphone.

Elle apparaît pendant une transition hors téléphone ou immédiatement après celle-ci.

Elle peut être conservée dans la Galerie comme mémoire du joueur, mais elle ne devient jamais :

- une pièce jointe ;
- une preuve ;
- un fichier possédé ;
- une image transférable ;
- une photographie découverte par un personnage.

### 4.2 Galerie

La Galerie archive.

Elle ne révèle jamais une image pour la première fois.

Une image devient accessible dans la Galerie seulement après avoir été rencontrée dans son contexte narratif.

Origines discrètes proposées dans le PhotoViewer :

```text
Reçue dans une conversation
Vue dans un groupe
Moment vécu
```

Aucun onglet visible « Souvenirs » n’est créé.

### 4.3 Retrait

Une photo diégétique peut devenir :

- active ;
- restreinte ;
- retirée ;
- inaccessible.

Son retrait peut bloquer son ouverture depuis la conversation et la Galerie.

Le retrait ne supprime pas :

- les messages ;
- la connaissance acquise ;
- les conséquences ;
- les images de scène représentant un moment réellement vécu.

### 4.4 Séquence adulte majeure

Un payoff adulte complet utilise normalement trois positions :

```text
1. entrée dans l’intimité
2. image centrale explicite
3. après-coup ou retour au réel
```

Deux images sont possibles lorsqu’une image existante paie déjà correctement l’entrée ou l’après-coup.

Dans la Galerie :

- une séquence adulte utilise une seule tuile principale ;
- l’ouverture permet de parcourir ses images dans l’ordre ;
- une image non vécue dans la partie n’est jamais accessible ;
- les variantes non servies restent invisibles ou verrouillées sans spoiler.
